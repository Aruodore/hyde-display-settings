# Product

## Register

product

## Users

The primary user is a HyDE and Hyprland user managing one personal Arch Linux workstation. The project may also be shared as an open-source utility for people with a similar setup.

## Product Purpose

Provide one trustworthy place to manage monitors, brightness, night light, idle behavior, and private local screen-time statistics. Success means everyday display and power changes no longer require remembering commands or editing several configuration files.

## Brand Personality

Quiet, precise, native. The interface should feel calm and immediately understandable, with the clarity of iOS settings adapted honestly to a Linux desktop.

## Anti-references

Do not resemble a gaming control center, a neon terminal dashboard, a generic web admin template, or a decorative iOS clone. Avoid excessive cards, glass effects, dense technical language, and hidden destructive behavior.

## Design Principles

- Put frequent controls first and advanced configuration one step away.
- Show the consequence of a setting before applying it.
- Prefer installed Hyprland tools over parallel implementations.
- Keep activity data local, minimal, inspectable, and erasable.
- Follow the active desktop theme and familiar platform conventions.

## Accessibility & Inclusion

Target WCAG AA contrast, complete keyboard navigation, meaningful accessible labels, color-independent states, and reduced-motion preferences. Use sufficiently large controls and preserve compatibility with GTK accessibility tooling.
